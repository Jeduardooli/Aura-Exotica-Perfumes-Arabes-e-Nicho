# NexusImports - Catálogo de Perfumes Árabes

## 🚀 Deploy na Vercel

1. Crie conta em [vercel.com](https://vercel.com)
2. Instale Vercel CLI: `npm i -g vercel`
3. No terminal: `vercel --prod`

## 📝 Atualizar Catálogo

1. Execute o scraper Python: `python scraper_perfumes_arabes.py`
2. Converta CSV para JSON (use o script de conversão)
3. Substitua `data/catalogo.json`
4. Deploy: `vercel --prod`

## ⚙️ Personalizar

- Edite `data/config.json` para mudar cores, WhatsApp, etc.
- Edite `assets/css/style.css` para ajustar design
- Adicione mais produtos em `data/catalogo.json`
